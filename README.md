Опис завдання:
Завдання полягає у створенні платформи для прослуховування та пошуку музики. Користувачі зможуть слухати музику, створювати плейлісти з улюблених треків, а також використовувати фільтри за жанрами та тегами музики. Додатково, платформа використовує OpenAI API для пошуку музики за допомогою штучного інтелекту.

Список застосунків/інфраструктури для запуску коду:

Visual Studio - для розробки та запуску проекту.

MS SQL Server Management Studio - для управління базою даних на локальному сервері.

ASP.NET - для створення бекенд-частини з використанням Entity Framework для взаємодії з SQL Server.

SQL Server - для зберігання даних про музику та користувачів.

Bootstrap - для створення визуального інтерфейсу.

Razor - для створення динамічних шаблонів HTML.

OpenAI API - для здійснення пошуку музики за допомогою штучного інтелекту.

Paket нугетів - для керування бібліотеками та залежностями.

Приклади використання програми:

Пошук музики: Користувач може ввести назву пісні або виконавця, і система знайде відповідні треки за допомогою OpenAI API.

Створення плейлістів: Користувачі зможуть створювати та зберігати списки своїх улюблених пісень для легкого доступу до них.

Фільтри за жанрами та тегами: Можливість фільтрувати музику за жанром або тегами для покращення користувацького досвіду.
